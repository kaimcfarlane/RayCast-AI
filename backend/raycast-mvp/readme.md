# RayCast AI — Backend

The backend perception pipeline and API server for RayCast AI, a multimodal AI glasses assistant that processes POV video and audio into structured context for real-time assistance.

## What This Does

Takes a video file, extracts frames + audio, sends frames to a vision model for scene analysis, transcribes the audio, combines everything into a **Context Packet**: a single structured JSON object that feeds into the reasoning agent.


## Context Packet Schema

The Context Packet is the core data contract between the backend and all downstream consumers (reasoning agent, frontend). Every video processed returns this shape:

```json
{
  "session_id": "",
  "source_type": "",
  "video_file_name": "",
  "frame_interval": 6,
  "timestamp": "",
  "scene": {
    "scene_summary": "",
    "objects": [
      { "label": "", "count": 1 },
      { "label": "", "count": 1 }
    ],
    "text_in_scene": [
      { "text": "", "confidence": 0.85 }
    ],
    "key_details": [
      "",
      ""
    ],
    "uncertainties": [
      "",
      ""
    ]
  },
  "transcript": ""
}
```


## Setup

### Prerequisites

- **Python 3.10+**
- **FFmpeg** — required for audio extraction from video

### 1. Clone the repo

```bash
git clone <repo-url>
cd backend/raycast-mvp
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Install FFmpeg

**Windows:**
```bash
winget install ffmpeg
```

**Mac:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt install ffmpeg
```

Verify it's installed:
```bash
ffmpeg -version
```

### 4. Set up your `.env` file

Create a `.env` file in the `raycast-mvp/` root:

```env
OPENAI_API_KEY=sk-your-key-here
```

If FFmpeg isn't on your PATH add the full path:

```env
OPENAI_API_KEY=sk-your-key-here
FFMPEG_PATH=C:\path\to\ffmpeg.exe
```

### 5. Create the outputs directory

```bash
mkdir outputs
```

### 6. Add a test video

Place a short video file (`.mp4` or `.mov`) in `tests/fixtures/`:

```
tests/fixtures/test.mp4
```

## Running the Server

```bash
python -m uvicorn app.main:server --reload --port 8000
```

The server will start at `http://127.0.0.1:8000`.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Root — confirms the API is running |
| `GET` | `/health` | Health check — returns status + version |
| `GET` | `/mock` | Returns a hardcoded Context Packet for frontend development |
| `POST` | `/analyze-video` | Upload a video file, returns a full Context Packet |
| `GET` | `/docs` | Interactive Swagger UI (auto-generated by FastAPI) |

### POST /analyze-video

Upload a video file as `multipart/form-data`. The server will extract frames, run scene analysis, extract and transcribe audio, and return a Context Packet.

**Response:** Returns a full Context Packet JSON (see schema above).

### GET /mock

Returns a hardcoded Context Packet with the same shape as `/analyze-video`. Use this for frontend development without needing the AI pipeline running.

```bash
curl http://localhost:8000/mock
```

## Notes

- **Supported video formats:** `.mp4` and `.mov` (iPhone recordings work directly — no conversion needed)
- **Frame sampling:** Extracts 6 evenly spaced frames by default (configurable via `FRAME_INTERVAL`)
- **Audio:** Extracted as 16kHz mono WAV before transcription
- **The Context Packet schema is the stable API contract** — frontend and reasoning agent should build against this shape. Internals may change but the output format stays the same.
- **Don't commit `.env` files** — API keys should never be pushed to the repo
